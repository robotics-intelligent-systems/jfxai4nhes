# Artificial Intelligence for Nuclear Hybrid Energy Systems

OPEN100 is a project that aims to provide open-source blueprints for the construction of nuclear power plants. Firefly is an open-source MSFBR. NucML is the first and only end-to-end python-based supervised ML pipeline. McCAD a CAD to Monte Carlo conversion library. DAGMC Direct Accelerated Geometry Monte Carlo. JADE, a novel nuclear data libraries V&V tool. TALYS is a software package for the simulation of nuclear reactions. (FUDGE) LLNL code for managing nuclear data. Research Reactor Simulator is a real-time graphical simulation code. TrioCFD is the Computational Fluid Dynamics (CFD) code based on the TRUST platform. The Ducted Assembly Steady State Heat Transfer Software (DASSH). Aurora is A Unified Resource for OpenMC (fusion) Reactor Applications. Cardinal accelerates scientific discovery in fusion and fission energy systems using high-fidelity multiscale and multiphysics simulation. ENRICO Exascale Nuclear Reactor Investigative COde. GeN-Foam is a multi-physics solver for reactor analysis. Moltres, a code for simulating Molten Salt Reactors. msre is a detailed cad model and openmc benchmarks of the molten salt reactor experiment. The SaltProc is a fuel reprocessing simulation tool for liquid fueled nuclear reactors. PyNE The Nuclear Engineering Toolkit. WATTS (Workflow and Template Toolkit for Simulation). Open-Source IEC nuclear fusion reactor control, monitoring, and data logging system. ROLLO (Reactor evOLutionary aLgorithm Optimizer). Research Reactor Simulator is a real-time graphical simulation. OpenReactor is a comprehensive nuclear reactor simulation tool. A package for Modelica simulating Molten Salt Reactors. DSNP is a system of programs and data files used to simulate nuclear power plants. DDNRS-ERSN is an Open Nuclear Reactor Simulator. ClaRa is a Modelica library for simulation of Clausius-Rankine cycles in power plants. MOOSE is an object-oriented C++ finite element framework. Armi is an open-source nuclear reactor analysis automation framework

The directory structure includes a specific folder for each phase of development and engineering programs:

- __MBSE__: The root folder Arcadia (ARChitecture Analysis and Design Integrated Approach) is a method of tools dedicated to systems engineering and architecture, supported by the Capella modeling tool.    
  - __CAD__: For computer-aided design.
  - __CAM__: Dedicated to the part manufacturing and assembly process.
  - __CAS__: For simulation of end-to-end functionality and performance analysis.
